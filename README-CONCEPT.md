# Алый — концепт цветочной мастерской

Портфолио-проект SITES / verver. Сейчас — два варианта главной для выбора направления; заказов и платежей нет.

## Посмотреть локально

Из этой папки: `python -m http.server 4179 --bind 127.0.0.1`, открыть http://127.0.0.1:4179/.

- `?direction=editorial&font=prata&mark=1` — «Обложка».
- `?direction=poster&font=cormorant&mark=4` — «Плакат».
- `&clean=1` — скрыть панель выбора для скриншотов.
- Без параметров панель внизу справа; на телефоне раскрывается нажатием.

Стек: HTML/CSS/JS без сборки. `index.html` — основная страница, `assets/css/concept.css` — стили/токены, `assets/js/concept.js` — интерактив. `concept.html` — начальная копия главной, актуальные изменения вносить в `index.html`. Снимки — `review/`. Решения и следующий этап — `DECISIONS.md`.
