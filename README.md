# Алый — цветочная мастерская

Многостраничный портфолио-концепт SITES / verver. Утверждено направление 01 «Обложка»: молочный фон, красный мак, Prata, утверждённый логотип «Неровный мак». Вымышленный бренд; заказы, оплата и сбор данных отсутствуют.

## Запуск

Из папки проекта: `python -m http.server 4179 --bind 127.0.0.1`. Открыть http://127.0.0.1:4179/. Без сборки и зависимостей.

## Страницы

Главная, каталог с фильтрами палитры, три страницы букетов, события, мастерская с историей сборки, конструктор `builder.html`, информация о концепте и авторе, 404. Предыдущий выбор направлений сохранён в `concept.html`.

## Как менять

Источник страниц — `scripts/build-pages.py` и сохранённая композиция `concept.html`. После изменения текстов/цен/ассортимента в генераторе выполнить `python scripts/build-pages.py`; готовые HTML включены в Git и работают без Python на хостинге. Цвета и типографика — CSS-переменные в `assets/css/concept.css`, дополнительные сетки — `assets/css/pages.css`. Навигация и фильтры — `assets/js/site.js`. Изображения — `assets/images/`, источники/права — `CREDITS.md`.

## Проверка и откат

Решения, результаты и ограничения — `DECISIONS.md`. Скриншоты — `review/`. Предыдущий этап сохранён отдельным коммитом. Архив и синхронизируемое зеркало SITES не изменяются.

## Публикация

Репозиторий: https://github.com/verver-vadya/site-aly, создан из site-template. Изменения через ветку и PR. Автопроверка запускается на PR и main: браузерный аудит шаблона плюс проверки модели конструктора, переходов и их жизненного цикла. Скриншоты — артефакт screenshots в GitHub Actions. Превью после одобрения и слияния: https://verver-vadya.github.io/site-aly/. В Settings → Pages выбрать GitHub Actions. Workflow собирает только публичные страницы и assets через `python scripts/build-preview.py`, добавляет метку коммита build; исходные исследования, review и PNG в публикацию не входят. По умолчанию noindex, для индексации концепта — PREVIEW_INDEX=true. Боевой запуск требует отдельного согласия Вадима.

## Движение и меню

`assets/css/menu.css` — круглая кнопка/раскрывающаяся панель, `assets/js/site.js` — фокус, Escape, закрытие вне панели. `assets/js/icons.js` подключает локальный Morphicons с MIT-лицензией. `assets/css/motion.css` — отклик кнопок и нативная смена композиции с увеличением фото между каталогом и страницей букета. `motion.js` пропускает переход при Enter и reduced motion; `motion-boot.js` не подключается. Для проверки: `node scripts/check-motion.mjs`.

В браузерах с `document.startViewTransition` (включая актуальный Firefox/Zen) `navigation.js` подгружает известные страницы и меняет main внутри текущего документа. Один механизм композиции и общих фото используется во всех поддерживающих браузерах; шапка сохраняется. Прямые ссылки по-прежнему открывают обычный HTML. История и прокрутка восстанавливаются, якоря не пересоздают текущую страницу. При ошибке загрузки выполняется обычная навигация. Конструктор монтируется/освобождается при смене страницы, его черновик сохраняется.

Браузеры без same-document API сохраняют старый выход/вход элементов вокруг обычной навигации (`motion.js`/`page-entry.js`). Проверки: `node scripts/check-navigation.mjs`, `node scripts/check-builder-lifecycle.mjs`, `node scripts/check-navigation-fallback.mjs`. Текущий отчёт: `review/shared-navigation-review.md`; прежний `review/zen-navigation-review.md` описывает упрощённый вариант.

Актуальная проверка: `review/restored-motion-review.md`. По уточнению Вадима чёрный кадр замечен во встроенном браузере Codex, а в обычном браузере вроде отсутствует. Причина не установлена, устранение чёрного кадра не подтверждено. `review/no-page-fade-review.md` описывает отменённое отключение анимации.

## Конструктор букета

Локально: `http://127.0.0.1:4179/builder.html`. Три палитры, восемь видов цветов со счётчиками (от 1 до 35 стеблей), объёмы 7/13/19, шесть оттенков упаковки и шесть оттенков ленты, а также варианты без них. Бутоны располагаются по глубине в двух измерениях, с разным поворотом, размером и выборочным отражением; 2–3 цветка имеют отдельную свободную раскладку. Фотографические стебли рисуются отдельно, зелень ограничена 1–3 веточками. Общий свет идёт слева сверху; контактные тени связывают слои, мягкая общая тень — весь букет. Листья зелени находятся за задним отворотом, нижний голый стебель — внутри упаковки; передние складки перекрывают растения своим реальным контуром. Состав хранится в localStorage, черновик переживает уход и возврат при подгрузке страниц. Данные никуда не отправляются. Условная стоимость пересчитывается по стеблям и бумаге. Экспорт — PNG1200×1500 с составом и пометкой о концепте. Morphicons меняет значок сохранения на галочку.

Ассортимент, условные цены и оттенки: `assets/data/builder-catalog.json`; генератор создаёт общий модуль `assets/js/builder-catalog.mjs` и элементы формы из одного источника. Старые черновики из четырёх видов мигрируют в текущий формат без потери выбора. Шаблоны: `scripts/builder-content.html`, `scripts/workshop-content.html`. Модель: `assets/js/builder-model.mjs`; общая отрисовка превью и экспорта: `assets/js/builder-render.mjs`; обработчики: `assets/js/builder.js`; стили: `assets/css/builder.css`. После изменений выполнить генератор. Проверки: `node scripts/check-builder.mjs`, `node scripts/check-motion.mjs`.

Проверены расчёты, жизненный цикл и офлайн-отрисовка, включая 35 цветов. Образцы экспорта — `review/builder-*-sample.webp`, это не скриншоты страницы. Браузерная проверка24.10.2026 заблокирована политикой инструмента. Нажатия, мобильная вёрстка и фактическое скачивание в браузере требуют проверки. Текущие подробности: `review/natural-builder-review.md`; предыдущие этапы — `review/builder-review.md`.

## Выбор логотипа и собственные иконки

`logo-preview.html?logo=1` — четыре направления в реальной композиции главной. Параметр logo принимает1–4; `clean=1` скрывает панель сравнения. Вадим выбрал первый вариант «Неровный мак»24.10.2026. Выбор записан в `assets/brand/selected.json`: генератор копирует утверждённые logo/mark/favicon в `assets/brand/`, обновляет шапку, подвал, знак в секции событий и SVG в экспорте PNG. Канонические файлы содержат надпись в контурах; SVG и favicon получают хеши в URL.

Исходные направления — `assets/brand/studies/`. После генератора страниц можно обновить страницу сравнения и листы командой `node scripts/build-logo-studies.mjs <путь к установленному @napi-rs/canvas/index.js>`; эта библиотека нужна только для авторинга и не включена в сайт.

Источник маленьких иконок — `assets/data/ui-icons.json`. Генератор страниц обновляет HTML и пути состояний в site.js/builder.js, затем пересчитывает хеши. SVG имеют currentColor и скрыты от скринридера рядом с текстом; текстовые подписи действий сохранены. Отчёт — `review/logo-icons-review.md`.
