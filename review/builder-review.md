**Block** для финальной визуальной приёмки: браузерный инструмент запретил доступ к localhost. Офлайн-отрисовка подтверждает состав графики, но не адаптивную вёрстку, реальное скачивание или удобство управления. Нужен просмотр локальной страницы пользователем либо восстановленный разрешённый доступ браузера. Никакого запроса на обход защиты нет.

Код движения: transform/opacity, strong ease-out 220 мс, отмена перед новым выбором; клавиатурный ввод немедленный, изменение reduced motion отменяет анимацию. Выборы доступны через нативные radio, счётчики имеют подписи и область 44×44, результат объявляет количество/стоимость. Сохранена предыдущая анимация перехода страниц; выводы о чёрном кадре не меняются.

Проверено: `node scripts/check-builder.mjs` — 23 750 корректных составов, инварианты перераспределения, границы, цена, данные localStorage, количество слоёв, ссылки всех страниц. `node scripts/check-motion.mjs` — 10 страниц и версии ресурсов. Синтаксис JS и `git diff --check`. Native Canvas: четыре вида по отдельности и три экспорта, непрозрачный фон, PNG 1200×1500; изображения просмотрены через view_image. `builder-*-sample.webp` — образцы экспорта, не скриншоты сайта. Дополнительная проверка: `node scripts/check-builder-render.mjs <абсолютный путь к установленному @napi-rs/canvas/index.js>`. Этот пакет предоставлен runtime для тестирования, сайту он не нужен.

Не проверено: загрузка страницы/модулей в браузере, нажатия/клавиатура, физическое скачивание PNG, восстанавливаемый черновик через реальную перезагрузку, короткий экран, 320/375/768/1280 px, OS reduced motion, Safari/iPhone, Windows125/150%, CPU×4. Браузерный доступ заблокирован до первого открытия новой страницы; UI не наблюдался.
